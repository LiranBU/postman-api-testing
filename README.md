# Postman API Testing Portfolio

## Overview
This repository contains API testing projects created using Postman for Trello API.

## Technologies Used
- Postman
- REST API
- JSON
- JavaScript

## Test Coverage
- CRUD Operations
- Authentication Testing
- Positive Testing
- Negative Testing
- Status Code Validation
- Response Body Validation

## Included Files
- Postman Collection
- STD (Software Test Design) document

## Features Tested
### Board
- Create Board
- Get Board
- Update Board

### List
- Create List
- Get List
- Update List

### Card
- Create Card
- Get Card
- Update Card
- Delete Card

## Notes
Trello authentication token may expire and should be regenerated in order to execute the collection again.
